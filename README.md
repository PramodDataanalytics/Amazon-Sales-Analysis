# Amazon Sales Analysis Using SQL

## Project Overview
This project analyzes Amazon India order data using MySQL to identify sales trends, product performance, customer order behavior, and order cancellation patterns.

## Objectives
- Analyze monthly sales trends and month-over-month growth.
- Compare B2B and B2C order behavior.
- Identify top-performing products and product categories.
- Analyze city-wise and state-wise sales.
- Evaluate cancellation and return rates.
- Compare fulfilment performance.

## Tools & Technologies
- MySQL
- SQL
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- PowerPoint for project reporting

## Key Analysis Areas
1. Monthly sales trend analysis
2. B2B vs B2C order comparison
3. Category and size performance
4. Top 10 SKUs by sales amount
5. City-wise and state-wise sales
6. City-level cancellation and return rates
7. Amazon vs Merchant fulfilment analysis
8. Category-level cancellation analysis
9. Best-performing category by colour

## Key Insights
- April recorded the highest monthly sales amount among the months analyzed.
- B2B orders had a higher average order value than B2C orders in this analysis.
- Bengaluru was among the leading cities by sales amount.
- Cancellation and return patterns differed by fulfilment method.

## Limitations
- March data covers only one day in the available dataset.
- Some sales totals may include cancelled orders, depending on the query.
- Return records may not be consistently available across fulfilment methods.
